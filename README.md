## Getting Started
1. Download v3.2.3.
2. Extract `LosslessScalingv3.2.3.zip`.
3. Run `LosslessScaling.exe`.
4. Pick a scale mode or an LSFG multiplier.
5. Set the game to borderless windowed, press the hotkey.
6. Notes in `files/notes/`.

<img width="1200" height="675" alt="images5" src="https://github.com/user-attachments/assets/73e1789a-6100-44c1-a9ad-343a352c3fc3" />

## Best settings
- LSFG x2 for 60 to 120 FPS, x3 for high-refresh
- LS1 for pixel-art, FSR for 3D
- WGC when DXGI hooks miss
- Cap the base framerate for stable pacing

## FAQ

**Steam Deck / Linux / Android?**

Any DirectX 11/12 card. Frame gen is not vendor-locked.

Windows 10/11 64-bit. Any DirectX 11/12 GPU.
